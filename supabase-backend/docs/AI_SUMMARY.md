# AI_SUMMARY

## Herramientas usadas

- OpenCode

## Uso principal

- Planificación de las iteraciones del backend Supabase.
- Generación inicial de la capa de servicios y de las políticas RLS.
- Corrección de errores y redacción de pruebas.

## Partes modificadas manualmente

- Configuración del proyecto Supabase.
- Nombres de tablas y campos.
- Políticas RLS.
- Validaciones y manejo de errores.

## Problemas encontrados con la IA

- Propuso usar el API de Supabase directamente en lugar de la capa de servicios.
- Generó políticas RLS incompletas.
- Inventó nombres de campos.

## Valoración personal

La IA sirvió para arrancar la capa de servicios, pero fue necesario revisar las políticas RLS y la
encapsulación de Supabase.
